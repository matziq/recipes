Recipe Editor

Add or update a recipe, then publish it directly to the family recipe site.

First-time access

  1. Ask the site owner to invite your GitHub account as a repository collaborator.
  2. Accept the invitation from GitHub.
  3. Create a classic GitHub token with the public_repo scope and a short expiration.
  4. Keep this page bookmarked. Paste the token only when you publish.

The token is not stored in cookies, local storage, or the recipe files. GitHub recommends giving tokens an expiration date and replacing them periodically.
